nm-sshuttle package repository

Fedora packages of nm-sshuttle, the NetworkManager VPN plugin that tunnels with sshuttle, built from source and signed by the nm-sshuttle project.

Install

Download the signing key file, and import it only if gpg --show-keys shows each fingerprint listed in the README on GitHub and no other key, and reports no error (install gnupg2 if gpg is missing). The fingerprint below comes from this site, like the key, so it proves nothing on its own. Then install the repository package with localpkg_gpgcheck=1, so that dnf checks its signature against the key; it does not check a package named on the command line otherwise.

curl -fsSLO https://dennisklein.github.io/nm-sshuttle/RPM-GPG-KEY-nm-sshuttle
gpg --show-keys RPM-GPG-KEY-nm-sshuttle
sudo rpm --import RPM-GPG-KEY-nm-sshuttle
sudo dnf install --setopt=localpkg_gpgcheck=1 https://dennisklein.github.io/nm-sshuttle/nm-sshuttle-release.noarch.rpm
sudo dnf install nm-sshuttle

To create and edit profiles in GNOME Settings as well, install nm-sshuttle-gnome. Source RPMs are in the nm-sshuttle-source repository (disabled by default).
